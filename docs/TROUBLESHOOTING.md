# 故障排查

## 数据源过期或离线

确认系统时间与网络可用，然后在“设置与请求日志”中启用数据源并点击“立即检查”。429、503、超时和断网会自动退避，最长 30 分钟；不要重复点击制造请求风暴。请求日志只显示脱敏目标、状态、耗时和结果数。

## DeepSeek 未配置或连接失败

在设置中粘贴 Key 并点击“安全保存”，随后使用“连接测试”。Key 只进入 Windows 凭据管理器。普通无关帖子不会调用 DeepSeek；候选分析失败时不会创建事件或发送通知。

## 没有预测

“暂无可靠预测”是安全状态，不是故障。应用不会根据历史间隔虚构概率；只有近期有效候选的结构化时间窗口才会显示在 24/48 小时卡片。

## SmartScreen

未签名版本可能显示“未知发布者”。只从项目 GitHub Release 下载，并先用 PowerShell 执行 `Get-FileHash -Algorithm SHA256 <文件>`，与同一 Release 的 `SHA256SUMS.txt` 对照。哈希不一致时不要运行。

## 数据损坏或重复通知

先退出应用并备份 `data`。索引可从 JSON 事实重建，损坏文件会隔离到 `quarantine`。通知按事件、渠道、语义版本和测试标志幂等；若仍重复，请保留 `notifications` 记录与脱敏请求日志用于诊断，切勿提交凭据。
