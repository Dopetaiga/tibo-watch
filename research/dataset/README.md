# 标注数据集

Phase 1 数据集只保存必要短摘录、帖子 ID、UTC 时间、标签、理由、哈希和原始 X 链接，不保存第三方页面副本。

状态约定：

- `provisional_secondary_lead`：由二级站点提供帖子 ID，再通过 FxTwitter 单帖接口核验作者、正文与时间；不能直接进入冻结测试集。
- `reviewed_primary`：人工查看 X 原帖与必要的父帖/引用上下文后完成标注，可进入规则研究。
- `unverified_secondary`：无法回溯一手链接，只能作为弱线索，禁止作为强正样本。

完整时间线采集必须包括 `@thsottiaux` 的原创、回复和引用帖，排除纯转推。当前 X 访客会话不返回回复时间线，需在已登录浏览器会话完成采集后才能声明六个月样本完整。
